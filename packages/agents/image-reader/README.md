# image-reader

Toy/demo agent, Python flavor (ADK-style). Takes an uploaded image, uses a vision-capable model to extract text and describe its contents. Fits the stateless/browser-upload model (no local filesystem needed), unlike its dropped sibling idea (a batch image-resizer, which needed real local gallery access and was cut for scope).
